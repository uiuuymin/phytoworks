# PhytoWorks Company Reference

## 문서 목적

PhytoWorks Shop의 회사·제품 맥락을 추측이 아닌 공식 자료에 맞추기 위한 기준 문서다. 2026-08-29에 아래 공식 페이지를 확인했다.

- PhytoWorks 한국어 홈페이지: <https://phyto-works.com/ko>
- NITRO 제품 페이지: <https://phyto-works.com/ko/nitro>

공식 사이트의 내용이 변경될 수 있으므로 실제 상품·화면 작업을 시작할 때 출처와 확인 날짜를 다시 검토한다.

## Confirmed — 공식 사이트에서 확인한 사실

- PhytoWorks는 재배, 환경 제어와 AI 기반 표현형 분석을 통합해 연구와 육종을 지원한다.
- `NITRO`는 독립 환경 제어, 비파괴 연속 관찰과 정량적 형질 분석을 결합한 플랫폼이다.
- 환경 제어 항목에는 온도, 습도, 광, 관수와 CO₂가 포함된다.
- 이미징 항목에는 RGB, 열화상과 엽록소 형광이 포함된다.
- 선택 모듈 후보로 Depth Camera, LiDAR와 RGB Stereo Camera가 소개되어 있다.
- 클라우드에서 촬영 세션, 환경 데이터와 생육 지표를 모니터링한다.
- Phenos는 식물 이미지와 데이터의 AI 분석 맥락으로 소개된다.
- 공식 사이트의 주요 전환은 온라인 구매가 아니라 카탈로그 다운로드와 문의다.

## Not Confirmed — 공식 사실로 사용하지 않을 내용

- NITRO와 각 모듈의 실제 판매 가격
- 온라인 직접 구매 가능 여부와 결제 조건
- 실제 재고 수량, 배송비, 세금, 납기와 환불 정책
- 분석 크레딧, 구독 요금제 또는 패키지 상품의 존재
- 로고·제품 이미지의 별도 재사용 허가

공식 사이트에서 확인되지 않은 내용을 회사의 실제 정책처럼 표현하지 않는다.

## Proposed — 학습용 쇼핑몰에 적용할 모델

- Product 범위는 생육 시스템, 이미징 모듈, 환경·관수 옵션과 분석 서비스로 제한한다.
- `QUOTE_REQUIRED`와 `DIRECT_PURCHASE`를 구분하는 판매 방식을 검토한다.
- NITRO 본체처럼 공식 사이트에서 문의 중심인 항목은 우선 `QUOTE_REQUIRED` 후보로 본다.
- Toss Payments 흐름을 학습하기 위해 일부 항목을 `DIRECT_PURCHASE`로 구성할 수 있다.

## Demo — 실제 회사 정책과 구분할 내용

- 화면의 가격, 할인, 재고와 직접 구매 가능 여부는 구현 task에서 만든 학습용 데이터다.
- Demo 가격이 포함된 화면에는 실제 PhytoWorks의 판매 조건이 아니라는 안내를 표시한다.
- 결제는 Toss Payments 테스트 환경만 사용하며 실제 판매나 실결제로 표현하지 않는다.

## 이미지와 브랜드 자료

공식 사이트는 참고 자료지만 공개되어 있다는 사실만으로 로고와 이미지를 자유롭게 복제할 수 있다고 가정하지 않는다. 사용 권한이 확인되지 않은 동안에는 자체 제작 placeholder를 사용하고, 참고한 자료의 URL과 사용 여부를 task에 기록한다.

공식 사이트의 시각적 특징을 Demo Shop으로 변환하는 원칙, 필요한 자산 후보와 responsive 방향은 [`../design/shop-ux-strategy.md`](../design/shop-ux-strategy.md)를 기준으로 한다. 이 연결은 공식 자산의 사용 권한을 의미하지 않는다.
